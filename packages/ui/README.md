Undo: C4 keeps one prior committed selection in `reskin.lastGood`. Undo selects it and records that lastGood's revision in `reskin.ui`, so the swapped-back theme is not offered as another Undo until a new choice.

Saving: the builder commits the repaired source with `saveCustom` and selects it, then `setCssConsent` for the sanitized hash when Enable advanced CSS is on (or revokes it when turned off). A saved theme it edits that changed elsewhere offers Keep editing this draft or Load saved theme instead of being overwritten. Imported CSS is off until the person enables it, and changing the CSS clears that choice.

Not in this stage: uploading a local image (it waits for the raster conversion helpers), and the popup has no Customize entry; the builder lives in the settings page.
