# @github-reskin/format

Theme format v1. Pure ESM with no DOM, storage, network or code evaluation. The schema is `theme-v1.schema.json`, the reviewed copy published at its `$id`.

| Export | Behavior |
| --- | --- |
| `parseImport(input, kind)` | `kind` is `text`, `file` or `code`. Bounds input by UTF-8 bytes (64 KiB file, 128 KiB pasted), decodes bytes as strict UTF-8, strips a BOM, then finds exactly one theme object in plain JSON, JSONC (line comments end at LF, CR or CRLF), a code fence or surrounding prose, or a share code or share link. Returns `{ok:true, source, normalized, notes}` or `{ok:false, issues, candidates?}`; `candidates` is `{name, input}[]` when more than one theme is present. Never repairs, resolves or saves. |
| `validateTheme(value)` | `{ok:true, theme}` or `{ok:false, issues}` with plain-language messages. Uses the precompiled standalone validator plus the link and resource-string ban, which scans each string in linear time. |
| `normalizeTheme(value)` | Documented equivalents only (color spelling, ASCII whitespace in text, font display names, a missing name, a missing schemaVersion on a v1 shape), each with an `info` note. Does not mutate its input. |
| `colorsOnly(value)`, `withoutForeignSchema(value)` | The two explicit choices after a failed import: a separately validated name/base/colors document with the `omitted` field list, and removal of a non-Reskin `$schema`. |
| `canonicalize(theme)` | Compact JSON with recursively sorted keys, the input to share codes and hashes. |
| `exportTheme(theme)` | `{filename, mime, bytes}`: `<name-stem>.reskin.json`, sorted two-space JSON, LF, final newline. Throws on an invalid theme. Callers export repaired source. |
| `encodeShare(theme)`, `decodeShare(code)` | `RS1.<base64url(zlib level 9)>.<crc32>`. Decoding accepts any zlib level, enforces the 16 KiB compressed and 64 KiB expanded limits while inflating, and returns an import result. |
| `makeAiPrompt(idea?)` | The generated prompt (`prompt-template.js`, from `scripts/generate-prompt.mjs`) with the idea as bounded plain text. |
| `catalogProblems(catalog)`, `ANIME_CATALOG`, `CLASSICS_CATALOG` | The catalog contract and the stable ID/slug table. |
| `acceptsFileName(name)` | Import accepts `.json` and `.reskin.json`. |

`index.d.ts` declares every export with types from packages/contracts; the `FormatModule` functions match it exactly, and `tests/format/module-types.ts` proves the module assigns to it under strict TypeScript without `allowJs`. `NOTE_CODES` and `ANIME_CATALOG` stay here until C1 adds them to packages/contracts.

`schema-validator.js` and `schema-registry.js` are generated by `node packages/format/generate.mjs`; `check:schema` fails when they differ from a fresh generation. `checks.mjs` exports `run({command, args, root, outDir})` for `schema`, `prompt`, `classic-themes` and `themes`.
