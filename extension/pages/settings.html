              Help
              
          
              
            
              GitHub looks unchanged
              
            
              Reload GitHub once to see your theme. If it still doesn't change, allow GitHub access in your browser's extension settings, then reload the page.
              
            
              GitHub accessibility colors are active
              
            
              High contrast or forced colors keep GitHub's own colors. Your theme choice stays saved and returns when they are off.
              
            
              A chatbot's theme won't import
              
            
              Use Copy AI prompt in Make a theme, then paste the chatbot's whole answer, including the lines with { and }.
              
            
              Something looks wrong on a GitHub page
              
            
              Report it on GitHub Reskin's Issues page. Colors keep working where it is safe.
